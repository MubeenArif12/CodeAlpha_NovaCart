# NovaCart – E-commerce Store

NovaCart is a full-stack e-commerce web application developed as part of the CodeAlpha Full Stack Development Internship – Task 1.

## Features

- Product listing
- Product search
- Product details page
- Shopping cart
- Quantity controls
- Cart total calculation
- User registration
- User login and authentication
- Order processing and checkout
- SQLite database
- REST API backend

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- SQLite
- JWT
- bcryptjs
- CORS
